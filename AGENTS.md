# React Native 0.86 (Community CLI) + Nx + Tamagui + RN Web

This is an **Nx npm-workspaces monorepo**, not Expo. Do not add Expo modules, `expo` config, Expo Router, Solito, or `docs.expo.dev` guidance.

Read the versioned docs at https://reactnative.dev/docs/0.86/getting-started before writing Metro, native, or Jest config.

- Apps: `apps/mobile` (Community CLI Metro, iOS, Android), `apps/web` (Vite + `react-native-web`, port 4200), `apps/storybook` (on-device Storybook), `apps/storybook-web` (Vite catalog Storybook, port 6006), and `apps/bff` (NestJS GraphQL BFF, port 4000).
- Packages: `packages/theme` (Tamagui tokens / `TamaguiRoot`), `packages/ui` (catalog), `packages/controller` (form bindings), `packages/network` (Apollo Client, no cache, codegen), `packages/language` (en/tr + language store), `packages/navigation` (route names / ref / headers), `packages/store` (auth + splash Zustand state only — no GraphQL), `packages/storage` (MMKV / web `localStorage`), `packages/native` (JS facades for native modules; haptic first), `packages/telemetry` (Sentry facade), `packages/views` (screen contents). Autolinked native modules live in `apps/mobile` and `apps/storybook`. Sentry stays in `apps/mobile`.
- Entry: `apps/mobile/index.js` → `App.tsx`. Storybook: `apps/storybook/index.js` → `App.tsx`. Web Storybook: `apps/storybook-web/.storybook`. Web: `apps/web/src/main.tsx` → `App.tsx`. Each product app owns only its `RootNavigator` (web chrome in `apps/web/src/shell`). Shared navigation lives in `packages/navigation/src` as `config/` (`screenDefinitions`, enums, types), `stacks/`, `screens/`, and `chrome/` (headers, ref, theme). Add a screen in `config/screenDefinitions` and map it — do not hand-write another `<Stack.Screen>`. Screen contents live in `packages/views`. Web-only route: `platforms: ['web']`. Same route, different UI: `Foo.web.tsx` next to the view. Scripts: `npm run ios` / `android` / `start` / `web` / `bff` / `codegen` / `storybook:ios` / `storybook:web`.
- Resolve every `@ds/*` package from its index (`import { Button, List } from '@ds/ui'`, `import { TamaguiRoot } from '@ds/theme'`, `import { Form } from '@ds/controller'`). Do not deep-import `@ds/ui/Button/Button`. Views, navigation, and apps import locale from `@ds/language` (`useTranslation`), not `react-i18next`.
- App session, splash, language, and theme preference are Zustand stores, not React Context. Tamagui still needs `TamaguiRoot`. Language lives in `@ds/language`. Auth/splash state lives in `@ds/store` (`setSession` / `signOut`) — no GraphQL there. Views call GraphQL through `useMutation` / `useQuery` / `useLazyQuery` from `@ds/network`.
- Catalog: Text, Button, Card, Section, Container, Icon, List, Sheet, Loading, Hud, Breadcrumbs, Header, TextField, Select, DateTimePicker, Pin, Tckn, Form, ProgressBar, Dots, BarGraph, LineGraph, SliderCarousel. Import them from `@ds/ui` / `@ds/controller`. Do not invent hex colors or extra RN `style` on those. Tokens come from Tamagui, not Restyle. Callers compose layout; catalog internals only keep styles the primitive needs (TextInput, native/web sheet chrome, chart canvas size, carousel snap sizes, list separators / content insets). Sheet is `Sheet` + `withSheet` from `@ds/ui` (native: gorhom from the bottom; web: `Sheet.web.tsx` from the right); `size="large"` gives it a fixed tall box for a scrollable body. Loading is `Loading` from `@ds/ui` (`ActivityIndicator`, works native + web). Hud is a root overlay (`Hud` + `showHud` / `hideHud` from `@ds/ui`): transparent fill, catalog Loading in the center. Mount `<Hud />` once next to the navigator. Stepper is ProgressBar and Dots (`activeStep` / `stepCount`, gap `$sm`). Graphs are BarGraph and LineGraph (native Skia, web recharts). Inputs are TextField, Select, DateTimePicker, Pin, Tckn. DateTimePicker is `@react-native-community/datetimepicker` on native (iOS sheet / Android dialog) and a date input on web. Header on web is breadcrumbs (`Header.web.tsx`); native stays title + back. SliderCarousel (`items: T[]`, `renderItem`, `variant` large=1 / medium=2; native horizontal FlatList, web vertical snap-scroll with a footer peek). GraphQL calls go through `@ds/network` (Apollo Client, no cache). BFF is `apps/bff` (`npm run bff`); regenerate operations with `npm run codegen`.
- Any data-driven list goes through `List` from `@ds/ui` — FlashList v2, one file for native and web (JS-only, no native module). Props are `data`, `keyExtractor`, `renderItem`, plus `itemType` (recycling pools), `gap` / `padding` tokens, `header` / `footer` / `empty`, `columns`, `masonry`, `onEndReached`, `sheet`. The host must bound it (`flex` or a height). Never `.map()` a long array into a ScrollView, and never add another `FlatList`. Inside a Sheet pass `sheet` (it swaps in gorhom's scrollable) and open the sheet with `size="large"`.
- Form is `Form` from `@ds/controller` (yup + react-hook-form). It binds catalog inputs; it is not a catalog primitive. `@ds/controller` is form code only — no stories or tests there. Stories live in `apps/storybook/src/forms`; Jest lives in `apps/mobile/src/forms`. Use `Form.TextField`, `Form.Select`, `Form.DateTimePicker`, `Form.Pin`, `Form.Tckn`; fields own `value` / `onChange` / `onBlur` / `error` themselves (`FormFieldProps`).
- React Compiler is on for mobile (`babel-plugin-react-compiler`, target 19). Skip `useMemo` / `useCallback` unless profiling shows a bail-out. Tamagui compiler is **web-only** via `@tamagui/vite-plugin`. Do not add `@tamagui/babel-plugin` on mobile unless asked.
- Haptics go through `haptic` from `@ds/native` (`selection` / `impact` / `success` / `error`). Catalog primitives fire them; web is a no-op. The Turbo Module lives in `packages/native` (`ios/` + `android/`) and autolinks via `@ds/native` in `apps/mobile` and `apps/storybook`.
- Fonts are native assets under `apps/mobile/assets/fonts/` and `apps/storybook/assets/fonts/` (linked with `react-native-asset`). After a clean clone: `npx react-native-asset` from each RN app, then `cd ios && bundle exec pod install`. Web fonts live in `apps/web/public/fonts` (also served by `apps/storybook-web`). Catalog icons are hand-drawn SVGs (`Icon` from `@ds/ui`), not Ionicons.
- On-device Storybook is `apps/storybook` (`npm run storybook` / `storybook:ios`). Web catalog Storybook is `apps/storybook-web` (`npm run storybook:web`, port 6006). Both reuse `packages/ui` CSF stories plus Form stories in `apps/storybook/src/forms`. Jest in `apps/mobile` reuses those stories via `composeStories`. Web-only Storybook tests: Vitest + Playwright (`npm run test:storybook`), `@storybook/addon-a11y`, coverage, Chromatic visual tests (`@chromatic-com/storybook`). `@storybook/addon-vitest` and a11y have no on-device support (`unsupportedFrameworks: react-native`). Chromatic snapshots are web/cloud only — they do not run in on-device Storybook. CI: the Visual tests job in `.github/workflows/pull-request.yml` with secret `CHROMATIC_PROJECT_TOKEN`. Product `apps/web` is not Storybook. Detox component e2e targets `apps/storybook` (`npm run e2e:ios` / `e2e:ios:build`). Launch with `launchArgs.detoxStory` (`select` / `loading` / `dots`) to mount a host from `apps/storybook/src/detox/DetoxHost.tsx`. Screen-level Detox is `apps/mobile` (`npm run e2e:mobile:ios` / `e2e:mobile:ios:build`): splash → demo login → home. Debug `.app` needs product Metro on 8081 (not Storybook) and the BFF on 4000 (`demo@example.com` / `demo`).
- Pin exact versions of `react`, `react-native`, `react-native-reanimated`, and `tamagui` via root npm `overrides`.
- RN performance / UI patterns follow Vercel [react-native-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-native-skills) in `.cursor/skills/react-native-skills/`. Read `PROJECT.md` there first; Expo-only rules are remapped.
